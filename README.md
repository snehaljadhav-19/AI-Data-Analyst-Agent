# AI Data Analyst Agent

An interactive data analytics platform built with Streamlit, Pandas, Scikit-learn, and Plotly. It helps users explore datasets, clean data, generate visualizations, train machine learning models, and create analytical reports.

## Features

- **Dataset Upload:** Upload CSV, Excel, and JSON files.
- **Data Cleaning:** Handle missing values and duplicate records.
- **Exploratory Data Analysis:** Explore dataset structure, statistics, distributions, and correlations.
- **Interactive Visualizations:** Generate charts using Plotly, Matplotlib, and Seaborn.
- **Machine Learning:** Train and compare classification and regression models.
- **Feature Importance:** Examine features influencing model predictions.
- **AI Insights:** Generate automated observations and recommendations from dataset characteristics.
- **Chat With Your Data:** Ask questions about your dataset using the built-in data query interface.
- **PDF Reports:** Generate downloadable analytical reports.

## Technologies Used
